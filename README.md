# ppe — ישראל בסדר העולמי · גלריית סרטונים

דף בית וגלריית סרטונים למיזם. הדף מציג נגן ראשי + תפריט של כל הסרטונים עם כותרת ותיאור.

## מבנה

```
ppe/
├── index.html      דף הגלריה (נטען אוטומטית ב-GitHub Pages)
├── videos.json     רשימת הסרטונים + כותרות ותיאורים (זה מה שעורכים)
├── videos/         קבצי ה-MP4
└── README.md
```

## איך מוסיפים סרטון

1. שמרו את קובץ ה-MP4 בתוך `videos/` (רצוי שם באנגלית, ללא רווחים — למשל `03-title.mp4`).
2. הוסיפו רשומה ל-`videos.json` בתוך המערך `"videos"`:

```json
{
  "file": "videos/03-title.mp4",
  "title": "כותרת הסרטון",
  "description": "תיאור קצר שיופיע בתפריט."
}
```

3. Commit + push. ב-GitHub Pages הגלריה תתעדכן אוטומטית.

## פרסום ב-GitHub Pages

Settings → Pages → Source: `Deploy from a branch` → Branch: `main` / `root`.
הכתובת תהיה: `https://israel-2026.github.io/ppe/`

## הערה על גודל קבצים

GitHub חוסם קובץ מעל **100MB** ומזהיר מעל **50MB**. הסרטונים כאן ~80MB כל אחד.
אם מצטברים הרבה סרטונים כבדים, שווה לשקול אחסון וידאו חיצוני (Git LFS / שירות וידאו)
במקום לשמור את ה-MP4 בתוך הריפו.
